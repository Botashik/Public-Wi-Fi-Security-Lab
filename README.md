# Public Wi-Fi Security Lab (Ethical Simulation)

**Tools:** Virtual machines, Wireshark, simulated networks  

**Description:**  
Simulated testing of public Wi-Fi network security in a controlled lab environment. The goal was to analyze network traffic, detect vulnerabilities, and learn how to protect users from common threats.  

**Objectives:**  
- Understand security risks in public Wi-Fi  
- Learn how to detect unsecured traffic  
- Practice network monitoring and ethical penetration testing  

**Outcome:**  
Successfully simulated a public Wi-Fi network and identified potential security risks in a safe lab setup.  

**Skills Learned:**  
- Network packet analysis  
- Ethical penetration testing  
- Public Wi-Fi security awareness
